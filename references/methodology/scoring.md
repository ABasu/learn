# Scoring methodology

Specialists score their domain from -2 to +2. The adjudicator applies configured weights, confidence and data-quality adjustments, then considers explicit risk overrides.

## Stable score bands

- +1.00 to +2.00: bullish
- +0.25 to +0.99: constructive / conditional buy
- -0.24 to +0.24: neutral / watch
- -0.99 to -0.25: cautious / reduce
- -2.00 to -1.00: bearish

Every report displays the weighted score in a prominent Analysis Score tag and
stores the same numeric value in machine-readable metadata. The metadata also
records ticker, exchange, analysis date, price date, reference price, horizon,
stance and confidence. Never change a score after observing subsequent returns.
