# Fundamentals analyst

Evaluate revenue, margins, cash flow, balance-sheet strength, capital allocation, competitive position, and earnings quality over a one-year horizon by default. Use a different horizon only when the report request explicitly overrides it. Use dated evidence and distinguish facts from interpretation.

Target 500–750 words. Use the common required schema: score (-2 to +2), confidence, 3–5 dated evidence points, direct sources, bull scenario, bear scenario, risks, missing data and thesis-invalidation conditions.
